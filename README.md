**O que vamos jogar juntos?** O AMIGOS Database é o catálogo que mantenho para quem procura jogos cooperativos ou de navegador. Dá para filtrar os títulos, abrir a ficha de cada jogo e consultar preços em reais pela integração com a CheapShark.

A interface tem seis idiomas. Uso **Vitest** nos testes unitários e **Playwright** para testar os fluxos de navegação de ponta a ponta.
