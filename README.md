## Como trabalho

- Entendimento antes da implementação: contexto, problema, restrições e impacto esperado.
- Código claro e sustentável: nomes objetivos, estrutura simples e decisões fáceis de manter.
- Entrega incremental: validar, implementar, testar, revisar e evoluir com feedback.
- Visão ponta a ponta: interface, API, banco, integrações, automações e documentação.

```txt
entender -> validar -> implementar -> testar -> entregar -> evoluir
```
